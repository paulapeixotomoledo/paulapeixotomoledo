Three research projects from my PhD and postdoc work, chosen because each one involves the same core skill this role needs: building a model that recovers structure from noisy, high-dimensional biological data, then trusting the result only after it survives an adversarial control.

Causal attribution in a biophysical circuit model

Simulation-based inference to identify the mechanism behind a pharmacological effect — manuscript in preparation

~25,000 neurons 50,000 simulations 8-parameter inference GPU + HPC cluster
  • Built an 8-parameter per-cell inference pipeline — sequential neural posterior estimation with a neural spline flow — run across two paradigms, nine time points, and two treatment groups.
  • Designed a counterfactual intervention framework to move from correlation to cause: shift one inferred parameter by the group-level delta, re-simulate, and measure how much of the observed group difference it recovers. Shapley-decomposed the contributions to separate individual effects from interactions.
  • Showed the attribution inverts with the choice of counterfactual — parameter replacement and parameter shift assign the effect to opposite mechanisms. Diagnosed why, and kept the failing version in the report as a documented pitfall.
  • Built the supporting infrastructure: resumable GPU inference with checkpointing, cached simulation/posterior artifacts, and an interactive HTML report that became the lab's shared reference for the project.

Latent-state decomposition of behavior

Hierarchical GLM-HMM recovering interpretable strategies from navigation data

K = 1–10 states tested leave-one-animal-out CV custom circular-data observations
  • Extended standard GLM-HMM architectures with custom observation models for circular data, plus optimization procedures to improve inference stability.
  • Performed systematic model selection using K-fold cross-validation, leave-one-animal-out validation, and stratified/balanced resampling with warm-start initialization.
  • Recovered latent states that each map onto an identifiable behavioral strategy rather than remaining an uninterpretable mixture — decomposing a complex system into named, individually inspectable components.

Year-scale population decoding from durable single-neuron recordings

Second author, IEEE MetroXRAINE 2026 (accepted)

7 animals 30–42 sessions each 4 adversarial controls
  • Built the end-to-end decoding pipeline from raw imaging data: non-rigid motion correction, cross-session single-cell registration tracking the same identified neurons across the full recording period, neuron-count normalization, and stratified cross-validation.
  • Benchmarked multiple decoder architectures under matched evaluation and diagnosed why the weaker performers failed, not just which ranked lowest.
  • Designed the adversarial control suite that carried the paper through review. A reviewer argued the accuracy could reflect temporal autocorrelation rather than genuine coding, so I built four independent controls to break my own result: block cross-validation with enforced temporal gaps, a circular time-shift lag sweep, per-neuron permutation, and label shuffling.
  • The controls settled more than the objection — they separated population-level coding from single-unit tuning, established temporal specificity, and surfaced a confound in my own analysis, which I reported.

Are attention head contributions additive?

Personal project, August 2026 · github.com/paulapeixotomoledo/interp-induction-shapley

A from-scratch replication of induction-head behaviour in GPT-2 small, extended with an exact Shapley decomposition of head ablations. The induction-head finding itself is established literature — the point of this project is six things I found while checking it that I was not looking for, each one caught by a control before I believed the wrong number. Every chart below is built directly from this project's own result files, not illustrative data.

Finding 1 — the counterfactual changes the answer

Does how you remove a head change which head looks important?

Five induction heads, ablated individually and across all 32 subsets; Shapley values computed exactly (not sampled) so they sum to the joint effect exactly, under three different ablation counterfactuals — zero (force output to 0), mean (force output to its batch mean), and resample (swap in the head's output from a different input sequence).

Finding 2 — most of the "interaction" was a choice of metric

Is 85% of the effect really interaction — or is that a property of measuring in log-loss?

I first reported "85% of the effect is interaction." That number is real for cross-entropy loss specifically — it drops to 21% under a near-linear metric (centred logit), measured on the same 32 subsets, same Shapley computation, same forward pass. Error bars are ± 1 SD across 5 random seeds. The README was corrected in place rather than rewritten to look right the first time.

Finding 3 — the same head, twenty times the cost, depending on order

Is a head's importance a fixed property of the head?

L4H11 (the dominant previous-token head feeding the induction circuit) costs +0.250 nats when ablated first in a cumulative removal sweep, and +5.23 nats — the same head, same model, same metric — when ablated last, after the heads it was backing up are already gone. "How important is this head" turned out not to be a well-posed question without specifying what else has already been removed.

The open question

Loss per token position across [BOS] + S + S (50 random tokens, repeated). The second copy is perfectly predictable given the ability to look back — but the loss does not collapse at the first repeated token. It takes 3–4 positions to reach floor, and only one of those is explained by there being no prior occurrence yet to attend to at the exact boundary. I don't know what accounts for the other two or three positions, and the repo notes say so rather than papering over it.

Finding 4 — attention and causal importance disagree

Does the head the model "looks at" most match the head that actually matters?

L5H5 places more attention on the induction diagonal than any other head (0.907, the correlational measure from Experiment 1) — but ablating it alone costs almost nothing (+0.046 nats). L5H1, ranked third by attention, carries almost the entire marginal causal signal (+0.640 nats). Attending to the right place and being load-bearing turned out to be different properties of the same head — which is the reason this project moved from scoring attention to ablating it.

Finding 5 — where induction actually lives, across all 144 heads

GPT-2 small has 12 layers × 12 heads. How concentrated is this behaviour?

Every one of the 144 attention heads in GPT-2 small, scored for attention placed on the induction offset diagonal. The five outlined cells are the heads used throughout this project. Scores don't fall off smoothly — there's a clear gap between the 5th-ranked head (0.814) and the 6th (0.509), then a second cluster at 0.45–0.51. Two tiers, not a gradient; whether that second tier is doing weaker induction or something else this metric happens to pick up is still an open question in the repo notes.

Finding 6 — checking whether a surprising result was noise

A head's ablation effect was slightly negative — removing it looked like it helped. Real, or noise?

L7H10's marginal ablation effect was negative on the first run and small enough to write off as noise. Shown here: all 5 independent random seeds, plotted individually rather than only as a mean. Every single one is negative — about six standard deviations from zero. It wasn't noise, and I had no explanation for it then and don't invent one now. L5H1 is plotted alongside for scale: a clearly real, clearly positive effect, for comparison.
