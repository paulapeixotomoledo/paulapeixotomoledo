
# Paula Peixoto Moledo, PhD

Computational neuroscientist at the Instituto Cajal (CSIC), Madrid.

I work out what neural circuits are computing. That usually means building probabilistic models: simulation-based inference, latent-state models, population decoders;  and then designing causal interventions to separate what merely *correlates* with a behaviour from what actually *drives* it. I run the experiments as well as the analysis: behavioural paradigms, in vivo calcium imaging, and the instrumentation that synchronises them.

**Interests:** simulation-based inference · latent-variable and state-space models · causal attribution · neural population decoding · mechanistic models of circuit function
